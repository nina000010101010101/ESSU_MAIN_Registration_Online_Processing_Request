Frequently Asked Questions

Answers before you start a request

Who can use this system?

Any currently enrolled or graduated ESSU Main student can create an account. Faculty and staff use the Admin ID to manage and process incoming requests.

How long does a document request take?

Most requests are evaluated and released within 3–5 working days, depending on the document type and completeness of requirements.

Can I pay online?

No. Applicable fees can be settled through a walk-in cashier.

What if my request is rejected or needs correction?

You'll receive a status update explaining what's missing or needs correction, and you can resubmit the same request without starting over.
